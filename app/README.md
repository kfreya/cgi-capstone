# App

This directory contains the Streamlit application for the CGI Capacity Analyzer
prototype.

- `app.py` is the Streamlit entry point. Run it from the repository root with
  `streamlit run app/app.py`.
- `mock_data.py` provides synthetic/demo support used when local processed data
  is unavailable.

These files are application source code. Do not place local CGI data, secrets,
or generated data artifacts in this directory.

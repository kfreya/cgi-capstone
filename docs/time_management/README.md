# Time Management

This directory contains course process and time-management artifacts.

- `week*_team_report.pdf` files are weekly team reports retained for historical
  and grading traceability.
- `final_report_2026-06-24.pdf` is the final project report referenced from the
  root README.

These files are documentation artifacts. Do not place source code, local CGI
data, generated private outputs, or secrets in this directory.

# Notebooks

This directory contains exploratory and historical notebooks used for EDA,
validation, and smoke checks.

- `eda.ipynb` contains exploratory data analysis work.
- `role2_validation.ipynb` supports validation and scoring-input review.
- `azure_chroma_smoke_test.ipynb` supports Azure/Chroma smoke exploration.

Notebooks are not the canonical final pipeline. Before submission, outputs
should be cleared or limited to safe, non-sensitive examples. Do not commit
CGI-derived row-level outputs, local credentials, or private generated data in
notebook cells.

# Outputs

This directory contains intentionally committed, redacted validation and
evidence artifacts for final handoff review.

- `rfp_validation/` contains proposal/RFP validation summaries and sample chunk
  artifacts.
- `rfp_evidence/` contains retrieval evidence summaries and path-comparison
  artifacts.

These tracked files are documentation/evidence artifacts, not the local CGI data
pipeline output location. Local CGI-derived generated outputs belong under the
ignored `data/processed/`, `data/vector_store/`, or related `data/` folders and
must not be committed.
